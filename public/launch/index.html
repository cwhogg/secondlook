Copy for each tweet, and — for the five tweets that need a custom image — a designed visual you can capture with a screenshot tool. Tweet 2 doesn't need a custom image; the URL auto-expands to the OG card you just shipped (previewed inline).

Every visual is designed at 16:9 (Twitter's optimal aspect) and uses the same brand system as the site.

How to edit the tweets

  1. Click into any tweet copy box below and just start typing. The border turns burgundy while you're editing.
  2. Character count updates live as you type. It turns red and says OVER LIMIT past 280.
  3. Refresh the page to restore the original drafts. Nothing is saved to disk — this is scratch paper.
  4. When you're happy with a tweet, triple-click to select the paragraph, then Cmd/Ctrl + C to copy.

How to capture each visual

  1. Mac: Cmd + Shift + 4, then drag over the framed visual. The screenshot lands on your Desktop.
  2. Windows: Win + Shift + S, then drag over the visual.
  3. Highest-res option (any OS): open Chrome DevTools (F12), Cmd/Ctrl+Shift+P, type "Capture node screenshot", click the visual's <div class="viz"> in the elements panel first, then run. Saves a PNG at native resolution.
  4. Zoom your browser to 125–150% before capturing if you want a sharper image.
